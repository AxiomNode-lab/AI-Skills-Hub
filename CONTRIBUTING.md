# Contributing

## Adding a skill source
1. Add or update a source manifest under `catalog/sources/`.
2. Record the exact repository and path.
3. Verify the applicable license at the skill level.
4. Add provenance and compatibility metadata.
5. Run validation locally.
6. Open a pull request with evidence for licensing and source origin.

## Principles
- Prefer upstream attribution over forks.
- Never assume a repository-wide license applies to every nested artifact.
- Do not vendor proprietary content.
- Avoid duplicate skills when an upstream canonical source exists.
