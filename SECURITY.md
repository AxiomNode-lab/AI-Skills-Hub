# Security Policy

## Scope
Report vulnerabilities in the AI Skills Hub code, registry pipeline, scanners, or bundled artifacts.

## Reporting
Please open a private GitHub security advisory where available. Do not publish exploit details in a public issue before remediation.

## Supply-chain principles
- Source commits are pinned.
- Every imported skill records provenance.
- License state is evaluated per artifact.
- Bundling is denied by default when licensing is ambiguous.
- Security findings must fail ingestion for blocked conditions.
