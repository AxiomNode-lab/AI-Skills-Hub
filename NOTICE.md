# Third-Party Sources

AI Skills Hub is a registry and integration project. Third-party Skills keep their upstream licensing; this repository does not relicense third-party artifacts.

## Current sources

- Anthropic Skills — https://github.com/anthropics/skills
  - Selected Apache-2.0 artifacts can be bundled only after artifact-level verification.
  - Proprietary document artifacts remain source-direct.
- obra/Superpowers — https://github.com/obra/superpowers
  - Repository license: MIT; individual Skills are still scanned before release.
- Vercel Agent Skills — https://github.com/vercel-labs/agent-skills
  - Some current Skills explicitly declare MIT in their own SKILL.md; others do not declare a license and remain review-required.
- Trail of Bits Skills — https://github.com/trailofbits/skills
  - Repository license: CC BY-SA 4.0; registry entries remain review-required until artifact-level redistribution is established.
- K-Dense Scientific Agent Skills — https://github.com/K-Dense-AI/scientific-agent-skills
  - Repository license: MIT; individual Skills declare their own licenses and runtime requirements.
- Microsoft Skills — https://github.com/microsoft/skills
  - Repository license: MIT; nested plugin/skill licensing is reviewed independently.
- GitHub Awesome Copilot — https://github.com/github/awesome-copilot
  - Community-curated source; ingestion is disabled by default.
- OpenAI Plugins — https://github.com/openai/plugins
  - Current OpenAI developer plugin manifest is proprietary; registry records are source-direct.

For exact legal terms, consult the upstream license and artifact-specific notices.
