# Third-Party Sources

AI Skills Hub is a registry and integration project. Third-party Skills are not relicensed by this repository.

## Current sources

- Anthropic Skills — https://github.com/anthropics/skills
  - Selected Apache-2.0 artifacts may be eligible for bundling when their artifact-level license is verified.
  - Proprietary artifacts such as document skills are source-direct.
- obra/Superpowers — https://github.com/obra/superpowers
  - Repository license: MIT.
- Vercel Agent Skills — https://github.com/vercel-labs/agent-skills
  - The repository currently states MIT in its README, but the catalog keeps these records review-required until a machine-verifiable license file is available.
- Trail of Bits Skills — https://github.com/trailofbits/skills
  - Repository license: CC BY-SA 4.0.
- K-Dense Scientific Agent Skills — https://github.com/K-Dense-AI/scientific-agent-skills
  - Repository license: MIT; nested artifact licenses require individual review.
- Microsoft Skills — https://github.com/microsoft/skills
  - Repository license: MIT; nested plugin/skill licensing is reviewed independently.
- GitHub Awesome Copilot — https://github.com/github/awesome-copilot
  - Repository license: MIT.
