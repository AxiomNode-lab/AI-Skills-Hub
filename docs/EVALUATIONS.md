# Evaluations

Trust metadata and behavioral quality are separate.

## Gates

- Structure validation verifies the Agent Skills file contract.
- License verification determines distribution eligibility.
- Security scanning detects capabilities and suspicious patterns.
- Behavioral evaluations measure whether a Skill actually produces its intended workflow.

The current repository contains evaluation definitions only. A future runner will execute reproducible tasks against client adapters and store immutable results.

Popularity, star count, or install count is never treated as an evaluation result.
