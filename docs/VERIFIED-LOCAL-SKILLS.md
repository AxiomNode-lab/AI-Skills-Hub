## PR #10 expansion held by PR #11

PR #10 commit `42117636827f64527f7a5e2bdfdba5375ad00aa4` proposed 139 additional releases: 19 from K-Dense, 118 from Microsoft, and 2 from obra. PR #11 independently compared all 598 proposed files with the three pinned upstream Git trees. Inventory, SHA-256, Git blob, mode, attached root-license, and ancestor/nested license checks passed. The exact skill and file list, source commits, license paths, automated instruction signals, and limitations are in [the expansion evidence](reviews/pr10-expansion-source-evidence.json).

That automated result does not establish a complete independent semantic review of the instructions. The 139 records therefore remain `review-required`, are not materialized, and are absent from the release lock. Their proposed review JSON remains as evidence to inspect, not as release approval. Three artifacts contain relative cross-artifact links, and many contain package installation, network, credential, or data mutation examples; those signals need a reviewer to resolve against the full instruction context.

`obra/using-superpowers` is also held. Its instruction requires `brainstorming` before planning/building, while `obra/superpowers/brainstorming` is blocked because its upstream path is missing. The dependency is now explicit in the catalog, and registry validation prevents an eligible skill from depending on a held, missing, or blocked skill.
